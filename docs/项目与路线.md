# 项目与路线

| 阶段 | 目标 | 当前 |
| --- | --- | --- |
| 阅读 0.0.1 | 发现 Desktop、邀请确认、只读配对、双方断开 | 已实现，使用 LMCP 1.0.0 的连接与读取子集 |
| 阅读 0.0.1 | 项目树、源码、文本和 IDEA 已打开的 JAR 内容自动匹配，支持按需高亮 | 已实现，范围跟随 IDE 可见表面 |
| 阅读 0.0.1 | 悬浮词卡、词条身份保护、连接中断后清除私人内容 | 已实现 |
| 独立使用与采集 | IDEA 本地词库、词本、语境采集和练习 | 后续设计 |
| 平台交付 | 更多 IDE 版本、Windows、Marketplace | 后续验收 |

IDEA 当作开发者阅读入口，Desktop 负责当前学习目标、个人资料与词库。连接时只读取当前词库和词卡。浏览器独立运行仍由 Browser 项目负责。

词汇高亮与词卡使用 IDE 的展示能力。后续练习也应使用插件自己的输入组件，保留原编辑器的 Undo、选区及输入法。词典资源使用 Desktop 已挂载的版本，遵循 Dictionary 的来源和数据许可。

本地体验见[开发与本地验收](开发指南.md)。架构与边界见[架构与接入准备](架构与接入准备.md)。
