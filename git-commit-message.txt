功能：完善词遇 IDEA 0.0.1 的只读遇见与签名发布

- 底部工具窗打开或重连后自动刷新，支持异步手动刷新和收起时暂停。
- 词表展示学习状态和收藏标签，支持搜索、筛选、表头排序及重置。
- 点选词条后展示桌面词卡并定位，提供可跳转的项目出处。
- 增加原生设置页，默认关闭持续高亮，保留主动定位的短时高亮。
- 使用本机 IDEA 和隔离桌面资料运行原生 UI 与端到端验收。
- 标签先验证兼容依赖和 ZIP 内容，再做签名及验签，然后创建 GitHub Release 草稿。
- 首版在 Marketplace 手工提交；后续自动上传单独读取 Token，并核对与草稿一致的签名包。
- 将 Marketplace 亮暗图标转换为矢量，并在打包时校验。
- 在插件包保留英文商店更新说明，仓库单独维护中文变更记录。
